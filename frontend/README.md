# Проект Vroomly

Веб-приложение для автовладельцев

## Технологии:

- HTML
- CSS
- React
- TypeScript
- Redux Toolkit
- React Router
- Vite
- Mantine UI

## Основные Команды

### Запуск сервера для разработки

```shell
npm run dev
```

### Сборка проекта

```shell
npm run build
```

### Форматирование, унификация кода

```shell
npm run lint
```

### Проверка приложения перед деплоем

```shell
npm run preview
```
